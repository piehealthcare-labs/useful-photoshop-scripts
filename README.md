# 유용한 포토샵 스크립트

업무 효율을 높여주는 포토샵 스크립트 5종 모음입니다.

## 포함된 스크립트

1. **A 아트보드별 저장**
   - 현재 문서의 각 아트보드를 개별 파일로 빠르게 저장합니다.
   - 문서명은 다음과 같습니다. *yymmdd_아트보드명_가로사이즈x세로사이즈px.psd*
   - 아트보드의 이름을 인용하여 파일명이 지정됩니다. <작업> 폴더의 상위 폴더 내에 있는 <첨부>\<기획서> 폴더 내 ppt,pptx 기획서 파일명을 조회하여 자동으로 해당 날짜로 지정합니다. 해당 경로에 ppt,pptx 파일이 없다면 저장 당일 날짜로 지정합니다.
   - 가로가 860px, 세로가 2000px 이상인 경우, 상세페이지로 인식하여 세로사이즈를 기입하지 않고 'yymmdd_아트보드명_860px'로 저장됩니다.
2. **B 열려있는 파일 모두 jpg 내보내기**
   - 포토샵에 열려있는 모든 문서를 일괄적으로 JPG 파일로 내보냅니다.
   - 이때 JPG 파일들은 현재 폴더의 상위 폴더 내에 있는 <시안> 폴더로 바로 저장됩니다.
3. **C 아트보드를 캔버스로**
   - 아트보드를 일반 캔버스 형태로 변환하고, 레이어 구조를 유지합니다.
   - 저장 시 대지 컬러를 바탕으로 최하위에 배경 레이어를 생성합니다.
4. **D 눈 감은 레이어 삭제**
   - 눈을 감은 불필요한 레이어들을 현재 파일에서 한 번에 삭제합니다.
5. **E 전체 크기 비율 조정**
   - 입력한 가로 사이즈에 맞춰 문서 전체(이미지, 텍스트, 마진 등)를 동일한 비율로 일괄 확대/축소합니다.

## 사용 방법

1. 포토샵을 실행합니다.
2. 상단 메뉴바에서 **[파일 (File)]** > **[스크립트 (Scripts)]** > **[찾아보기... (Browse...)]** 를 클릭합니다.
3. 실행할 `.jsx` 파일을 선택하면 스크립트가 실행됩니다.
4. 자주 사용하는 스크립트는 포토샵이 설치된 폴더 (응용프로그램\어도비포토샵) 내의 `Presets/Scripts` 경로에 넣으면 메뉴에 바로 표시되어 더 편리하게 사용할 수 있습니다. (현재 실행 중인 포토샵 프로그램을 모두 종료한 후, 다시 시작해야 정상적으로 적용됩니다.)
